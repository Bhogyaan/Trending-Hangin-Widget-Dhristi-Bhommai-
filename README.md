
# 🪬 Trending Hanging Widget (Dhristi Bhommai)

A lightweight, interactive Windows desktop widget inspired by the traditional **Dhristi Bhommai (Drishti Bommai)**. It brings a hanging companion to your desktop with smooth physics-based swinging and a minimal, distraction-free experience.

Built with **Electron.js, React.js, and modern web technologies**.

## 📂 Project Architecture

The source code is maintained in a private repository.

This public repository is used for distributing compiled Windows application releases.

```text
Private Source Repository
        │
        │ GitHub Actions
        ▼
Build React + Electron Application
        │
        ▼
Generate Windows EXE Files
        │
        ▼
Publish Release Assets
        │
        ▼
Public Release Repository
```

The public repository contains release downloads rather than the application's private source code.

---

## 🔄 Release Updates

New releases are automatically generated when changes are pushed to the configured production branch.

The automated workflow:

1. Installs project dependencies.
2. Builds the React frontend.
3. Packages the Electron application.
4. Generates Windows EXE files.
5. Uploads the files to the public GitHub Release.

The `latest` release contains the most recent published build.
